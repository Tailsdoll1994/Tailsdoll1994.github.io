## О проекте

Это одностраничное приложение (SPA), которое служит цифровым резюме и портфолио. Сайт демонстрирует:
- Профессиональный профиль с фотографией и базовой информацией
- Историю работы и опыт
- Профессиональные навыки
- Красивый интерактивный интерфейс

## Как это работает

### Структура страницы

Сайт построен на основе одного HTML-файла, который содержит:

1. **Заголовок профиля** - содержит имя и информацию о разработчике
2. **Фоновое изображение** - декоративный фон с эффектом градиента
3. **Аватар** - фотография профиля
4. **Раздел "Биография"** - краткое описание
5. **Раздел "Резюме"** - информация о рабочем опыте:
   - Должности и компании
   - Даты работы
   - Список обязанностей
   - Используемые технологии и навыки

### Интерактивные элементы

- **SVG иконки** - встроенные векторные иконки для визуального оформления
- **Анимированный фон** - частицы, создающие эффект глубины (используется библиотека particles.js)
- **Адаптивный дизайн** - сайт корректно отображается на устройствах разного размера

## Как это реализовано

### Технологический стек

- **HTML5** - семантическая разметка страницы
- **CSS3** - стилизация и анимации:
  - CSS переменные для управления цветами и шрифтами
  - Градиенты и маски для визуальных эффектов
  - Медиа-запросы для адаптивности
  - Flexbox/Grid для расположения элементов
- **JavaScript** - интерактивность:
  - Подключение particles.js для анимационного фона
  - Управление динамическим содержимым

### Структура проекта

```
/
├── index.html           # Основной файл с разметкой
├── styles.css          # Таблица стилей
└── src/
    ├── avatar/         # Изображение аватара профиля
    ├── background/     # Фоновые изображения
    ├── icons/          # SVG иконки
    └── spec/           # Спецификации и документация
```

### Ключевые особенности

1. **Многоязычность** - поддержка русского и английского языков через data-атрибуты
2. **Оптимизация** - минимальное количество зависимостей, использование CDN для внешних библиотек
3. **Семантическая разметка** - правильное использование HTML5 тегов для улучшения SEO
4. **Модульная структура CSS** - переменные для легкого изменения темы и цветов
5. **Внешние зависимости**:
   - Particles.js (CDN) - для анимированного фонового эффекта
   - Google Fonts - для типографики

### Оформление

- **Цветовая схема** - тёмная тема с неоновыми акцентами
- **Шрифты** - Roboto для чистого и современного вида
- **Эффекты** - маски градиента, прозрачные элементы, анимированные частицы
- **Компоновка** - центрированный макет с карточками информации

## Расширение функционала

Для добавления новых разделов или изменения контента:

1. Отредактируйте HTML-структуру в `index.html`
2. Добавьте стили в `styles.css` согласно существующей системе переменных
3. Поместите изображения в соответствующие папки в `src/`
4. Используйте data-атрибуты для поддержки многоязычности
